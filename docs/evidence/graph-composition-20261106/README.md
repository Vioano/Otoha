# 图引用存储边界：Linux 实机记录

[linux-x86_64.json](linux-x86_64.json)由[最终探针](../../../experiments/graph-composition/probe.py)生成，SurrealDB 3.3.5、Linux x86_64，8 项预期检查全部通过。运行时间记录为 UTC；本轮在台北时间 2026-11-06 执行。

其中一项成功检查是明确确认限制：企业库中的 `ENFORCED` 边尝试连接仅存在于支付库的 `node:refund` 时返回 `NotFound`，失败边未落盘。其他检查覆盖普通属性引用、同名本地 ID 的数据库隔离、显式映射路由及删除引用不会删除其他引用或目标记录。

测试用 `p.ref.graph_id` 只是样本约定。未实现或验证 Otoha Resolver、权限、历史版本、联合快照、跨库事务或迁移。原始响应和脚本/helper/二进制 SHA-256 保留在 JSON 内；没有保存测试密码或真实用户数据。

本次数据库可执行文件为 352,368,104 bytes，一次启动至健康状态为 710.44 ms。这些数值包含本轮环境条件，仅作为运行描述，不是性能基准。实验只使用认证的回环地址和临时数据，结束后停止进程并删除临时数据库。
