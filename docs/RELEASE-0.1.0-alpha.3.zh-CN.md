# Otoha 0.1.0-alpha.3 候选范围

2026-11-07。当前候选为 `0.1.0-alpha.3-rc.3`。本文说明首版内置穿透与自助初始化的范围；具体构建、公开下载和五分钟盲测另按实际结果记录，不以命令存在代替验收。

## 普通团队的默认路径

队长把产品 GitHub 链接交给现有 Agent。Agent 下载原生 CLI，执行 `init`，根据 CLI 的问题补问团队名、成员、权限与本机保存数据的意愿，再由 CLI 初始化网络、通信、数据库、私有仓库和个人邀请。队友通过自己的 Agent 使用对应邀请加入。

首版由队长电脑或已有机器托管权威数据。协作期间该机器需要在线；内置中继提供跨网络连接，不提供关机后的数据托管，也不会自动购买云资源或替人创建付费账号。

## 本轮实现内容

- `otoha init`：简短问题、答案文件或命令参数、持久进度、同一请求恢复。队长就绪与等待队友加入分别报告。
- 成员接入成功后自动上报本机资源检查；`otoha team wait` 对预期成员作有界等待，给出明确的全员初始化结果。报告与人类验收、当前持续在线分别判断。
- 内置默认 frp 中继接入：每团队独立连接凭据与路径，自动配置、启动、连接验证、续租与恢复；客户无需自行配置中继、域名或证书。
- 按需下载固定中心运行时：Python 3.12.12、SurrealDB 3.3.5、frpc 0.72.0。小客户端不要求 Go 或 Node.js；成员无需下载中心运行时。
- 本地私有 Git 仓库与 starter `main`：共享 Otoha 项目身份，成员可推送、reader 只读。原 Gitea 绑定方式继续保留。
- 带完整 URL 前缀的邀请、API、Git、事件和图谱访问；图数据库只在中心环回监听，远端通过 Otoha 图谱 API 操作。
- 自由 Property Graph 的基础修改、有界读取、条件版本和持久请求回执。旧架构图预览保持兼容，没有对公网开放其未认证读取接口。

初始化不导入当前工作目录，不接管旧中心、真实数据库或已有 receiver。升级或迁移既有团队仍需按其版本和数据单独核对。

## 平台、体积与前提

当前发行平台为 macOS Apple Silicon、Linux x86_64。系统 Git 是首版前提；Linux 后台接收还需要可用的 user systemd 会话，最小容器未必具备。缺少前提时应明确报告，不能声称全部初始化完成。Windows 和完全没有命令执行能力的 Agent 宿主尚未验证。

中心运行时压缩包约 Mac 109 MiB、Linux 138 MiB；精确字节与 SHA-256 以发行 manifest 为准。冷下载、解包和启动都计入五分钟，不能预装后把它们移出计时。

默认中继是受容量限制的 alpha 服务，当前注册协议公开声明活动路由和总登记容量；达到上限应报告不可用。路由租期由客户端自动续租，撤销会拒绝后续连接授权；已建立连接是否被立即切断不在该承诺内。中继运营费用、长期服务等级和更多地区仍待确定。

默认中继终止公网 HTTPS，再通过加密隧道转发到队长机器。中继运营方仍在通信的信任范围内；当前没有让中继也无法读取内容的端到端加密。权威存储在本机不等于内容对中继运营方保密。

## 五分钟验收

从较弱 Agent 的干净会话第一次收到产品 GitHub 链接开始连续计时，直到队长与及时响应的队友都完成加入、网络和初始化能力通过实际检查。对话、模型思考、下载、配置、基本验证与等待都计入。

测试使用虚构团队和隔离状态；若用程序模拟及时回答和转交邀请，须明确报告模拟方式。不能向盲测 Agent 提供作者命令、开发目录、预置网络或已经初始化的数据库。基础操作系统、宿主工具与已有软件前提预先记录。保留首次失败、超时、完整时间线和后续修改，不只报告最快一例。

五分钟是普通团队接入的验收目标。特定 Linux 双人样本或一个模型通过，不等于所有平台、模型、网络和复杂团队均已通过。具体证据在测试完成后补录。

RC1 与 RC2 两轮均未通过五分钟验收。队友分别在约 163 秒、184 秒加入，但模型的固定等待、重复核对和额外回执往返使完整独立验收未能及时完成。RC3 将接入检查和全员初始化结果收进 CLI，减少手工收尾协议。两轮记录、测试装置问题与后续成绩见[接入验证记录](ONBOARDING-VALIDATION.zh-CN.md)，不删除或倒扣失败耗时。

冻结前开发验证已通过：Go 全量测试和 vet、协作后端 78 项（含真实 SurrealDB）、中继 9 项，以及仓库现有完整测试入口。Mac 隔离联调通过真实公网路径、owner/member/reader 的图谱与 Git 权限、摘要与正文读取、同一初始化恢复，以及中心停启后的原请求自动续投。该联调用了缓存运行时，不能作为五分钟冷启动盲测成绩。

## 保留的限制

完整成员副本、逐消息私发权限、新的通用图谱画布、Template 引擎、历史版本重放、多主写入和任意宿主通知均未完成。receiver 运行、消息入库、宿主接受和 Agent 实际阅读分别判断。

全员检查报告是初始化状态，不自动证明用户验收或成员仍然在线；实际网络、正文、图谱读写、Git 传输和权限边界仍须按验收范围验证。

原 `0.1.0-alpha.2` 与团队候选已发布字节保持原样。若候选测试需要修改程序，后续候选使用新版本与新文件，不覆盖已发布资产。
