# 依据怎样改变制作与审查

以下为虚构的通用示例，不是某次真实测量或通过记录。它们借鉴“整体导演、明确继承＋特例推导、原生复核”的方法，不规定所有作品复制某种构图。

## 整体节奏

一场讲解连续十四页都是标题加段落，逐页字体清楚，也可能让观众一直做同一件事：读文字。先判断这段究竟在引入情境、解释机制、比较选择还是练习。若观看任务发生变化而画面始终不变，比较能表达这些变化的构图；若文字本身就是要细读的作品，保留文字并安排适合的阅读节奏。不是每隔几页强插图片。

审查时连续观看这一段及前后承接，再说明何处失去推进、具体替代怎样改变理解。拼图能发现重复，却不能独自验证时间与讲述节奏。

## 分层推导示例

虚构任务：让家长在亲子冲突中练习先确认情绪、再协商下一步。

- 整场目标与弧线：从辨认自己的惯常反应，走到能尝试一种新回应；结尾回到开场情境检验改变。
- 段落：先看一次冲突，再比较两种回应，再解释差异，最后演练。解释先于情境可能过于抽象，演练早于辨认可能变成背话术，顺序因目标而定。
- 页面：比较页只承担“看见两种回应造成的差异”，完整理论在下一页展开，不能同时塞入所有方法。
- 元素：两段对话共享情境与起点，角色锚点和回应位置保持可比较；表情插画只保留影响判断的细节，不为填空位加装饰。
- 动画（若采用）：先停在共同起点，让观众预测，再分别出现回应和反应；时间安排服务于比较任务。静态版本也可以用相邻页完成同一目标，无需强加动画。

Verifier 既审这条上层到下层的选择链，也连续观看真实作品。若比较页很清楚，但整段仍未把练习引向整场目标，两条链没有同时成立。

## 元素依据

| 元素或决定 | 可核对的依据 | 不足以放行 |
| --- | --- | --- |
| 对话的两侧排列 | 角色身份与轮次先后；真实最长对白样张；两侧位置是否帮助辨认 | “用了双栏，所以清楚” |
| 场景插画 | 画面需保留的行为与表情；主体比例及裁切；它与讲述发生的时刻 | “让这一页有图” |
| 图片裁切后的等比放置 | 按有效源窗口计算比例，再核对实际成品的图框与裁切；要求等比时两者须相符 | 代码写了 `contain` 或对象带锁定比例声明，就认为实际没有拉伸 |
| 通用页码 | 引用已验证导航角色与保护区；每页实际位置与遮挡检查 | 所有元素一律填“遵循网格” |
| 方法步骤 | 当前关系适合顺序、分支还是循环；比较实质不同的阅读路径 | 在段落外套圆框，再称“图解” |
| 动画停驻 | 观众此刻要识别的状态、可读标签、实际完整播放 | 只写“增强节奏感” |
| 辅助说明 | 删除后是否失去识别、决策、后果或恢复信息 | 每段都能事后编一句“帮助理解” |

标题下的概括即使包含事实，也不自动成为必要正文。核对它与相邻标题、实际例子、状态和证据是否重复；删除后判断不受影响，就去掉这个固定层。需要独立讲清的知识则以实际内容、图解或例子承担，不为每个标题例行补总结。

每个元素能关联到适用的公共依据或实际特例。公共依据先证明其任务与使用条件，再由实例继承；发现新冲突就重新设计。版本、时间、原草稿和实际候选保留在项目已有位置，不为此虚构历史或强制建立数据库。

最薄记录可以只写：`P08任务→所属段落；通用项→网格/字形/页码依据版本；特例→两种回应的角色锚点、真实候选及选择；实际文件→渲染图；观察→问题与复看范围`。它是引用结构，不是再建一份逐字账本。

若用户喜欢某张样图，先分清其偏好的是构图、材质、角色还是具体文字。不能仅凭文字描述就声称看过样图；取得原图后审其实际关系。用户明确要求与既有约束发生冲突时，回到当前指令和对齐链路作具体取舍，既不盲抄违规部分，也不静默改掉明确要求。

## 一条审查意见应能被复看

例如：“P08 的两位角色用了相同位置和色彩，连续阅读第三轮时难以辨认是谁说话。原任务要求对比两种回应，草稿的角色锚点在成品中消失。请恢复明确角色归属并复看 P07–P09。”

它同时指出实际画面、理解影响、依据差异和复看范围。仅写“排版不高级”不够；仅写坐标或“对齐通过”也不够。

改稿后按当前实际文件复看。若只验证了 PDF 静态页，就只报告静态页；独立 MP4 能播放不证明嵌入 PPTX 能播放，预计六十分钟不证明真人彩排已经完成。

## 把可计算部分和视觉判断配合起来

虚构例子：三个接近正方形的图片裁窗，被放进三个较宽的横向框。先计算裁后有效源尺寸与实际图框比例；如果采用要求是等比，声明的 `contain` 不能覆盖实际拉伸。PPTX 可核对实际裁切与放置结构，再看真实导出及约定宿主中的人物比例。修好几何后，仍须判断人物动作是否表达页面任务、三图尺度是否协调、与相邻页画风是否连贯。这些判断不能由比例检查代签。

另一类问题是文字卡在图像与底色的边界。即使文字框没有溢出，也要看它是否跨越不同明暗、切断人物或物件、破坏完整场景；临时加白条也可能遮掉叙事所需的动作。按任务重新划分图文空间，再看实际画面，而不是只给文字框加背景。

三项并列行动若只需先选一项，选择约束是必要信息。可以用明确的可选关系呈现，不能因反对辅助概括而把约束一并删掉。暖色、有插画、结构检查完成和一位独立审阅者在场，都不能自动证明整体美术成立。
