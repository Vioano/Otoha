# 附件与验证依据

在 GitHub Issue/评论页面上传图片、PDF 或其他支持的附件，也可以给团队可访问的资源链接。具体支持类型和大小以 [GitHub 附件文档](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/attaching-files)为准。CLI 附件选项需先查本机 `gh issue create --help` / `gh issue comment --help`；不支持时使用网页上传。

代码、测试和文档通过 PR 提交；大型构建产物和录像按团队约定存放，给出版本或校验值。私有附件需验证队友可访问。本机路径无法作为跨用户链接，工具仓库公开也不意味着团队数据应公开。

收件 Agent 根据任务实际查看截图、文档或影音；只读文件名或文字链接不能说看过内容。长视频给关键时间点。结论标清证据来自实际运行、静态阅读还是他人的报告。
