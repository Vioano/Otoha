# Otoha 成员接入

由项目所有者提供属于本人的接入包，并通过可信渠道核对来源。接入包包含个人凭据，应保存在仓库外的私有目录。

```sh
python3 onboard.py --bundle /PRIVATE/member.bundle.json --directory /PRIVATE/otoha-member
```

具体参数以 `python3 onboard.py --help` 为准。已有身份不应重复登记；中断后保留原邀请、待登记记录和投递日志，再核对结果。

接入后使用个人身份执行 `manifest` 和 `protocol`，核对真实身份、项目授权与频道。分别验证读取、写入以及当前宿主的会话投递，不能把工具调用成功当成 Agent 已读。

这份指南没有配置任何真实服务器，也不自动安装或迁移既有后台服务。
